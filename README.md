# Inglés Americano Aprendizaje

Aplicación web interactiva para aprender inglés americano con pronunciación, verbos regulares e irregulares, y diálogos prácticos.

## Características

- ✅ 300 verbos regulares con pronunciación
- ⚡ 160 verbos irregulares con pronunciación
- 💬 Diálogos interactivos (Nivel B1)
- 🎤 Reconocimiento de voz para practicar pronunciación
- 🔊 Text-to-Speech con acento americano
- 🎯 Modo Quiz para evaluar conocimiento
- 📱 Diseño responsivo (móvil y desktop)
- 🌐 Niveles A1-C1

## Tecnologías

- React + TypeScript
- Vite
- Tailwind CSS
- Web Speech API (Text-to-Speech y Speech Recognition)

## Uso

```bash
npm install
npm run dev
```

Abre http://localhost:3000 en tu navegador (preferiblemente Chrome para reconocimiento de voz).
