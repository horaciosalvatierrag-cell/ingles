## Atribución de verbos frasales

La lista de 400 verbos frasales, sus definiciones y ejemplos se adaptó del conjunto de datos **WortUniversum English Vocabulary Database**, de CrispStrobe, publicado bajo **Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)**.

- Fuente: https://huggingface.co/datasets/cstr/grundwortschatz-voc-en
- Repositorio y atribución detallada: https://github.com/CrispStrobe/WordUniverse/blob/main/DATA_LICENSE.md
- Licencia: https://creativecommons.org/licenses/by-sa/4.0/
- Cambios: se seleccionaron las 400 entradas de verbos frasales, se conservaron ejemplos por nivel y se transformó el esquema a JSON para esta aplicación. Se añadieron ejemplos de respaldo de Wiktionary cuando una entrada no tenía dos ejemplos por nivel y se redactaron dos ejemplos propios para “ride along”, que no tenía ejemplos en la fuente.

El archivo `phrasalVerbs.json` es contenido derivado y se distribuye bajo CC BY-SA 4.0. El resto del código no queda sujeto a esta licencia por la inclusión de este archivo.
